Mathematical Spirograph Generator

A Spirograph is a classic geometric drawing toy that creates intricate mathematical curves (epitrochoids and hypotrochoids) using rotating circles. This interactive generator uses the HTML5 <canvas> API and client-side JavaScript to trace the pen's trajectory in real-time.

x(t) = (R + r) · cos(t) - (r + O) · cos(((R + r) / r) · t)
y(t) = (R + r) · sin(t) - (r + O) · sin(((R + r) / r) · t)

Where R is the fixed outer circle radius, r is the rotating inner circle radius (must satisfy r ≤ R), O is the pen offset from the inner circle's center, and t is the continuous angle variable that increments from 0.
