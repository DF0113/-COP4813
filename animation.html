Technical Implementation & Motion Analysis

  1. Canvas Coordinate System: The HTML5 Canvas coordinate origin (0, 0) is located at the top-left corner. The X-axis extends positively to the right, and the Y-axis extends positively downward.
  2. Diagonal Trajectory Math: When the horizontal velocity component dx and vertical velocity component dy are equal (e.g., dx = 3.54 and dy = 3.54), the object travels along a 45-degree angle diagonal path: θ = atan2(dy, dx) = atan2(3.54, 3.54) = 45.0°.
  3. Boundary Clamping & Bouncing: To prevent the object from penetrating or escaping the bounded rectangle, the object's radius is accounted for: leftBound = 0 + radius, rightBound = width - radius, topBound = 0 + radius, bottomBound = height - radius. Upon contact, dx = -dx or dy = -dy reverses the respective velocity vector, producing an elastic bounce.
  4. Timer-Based Animation vs. requestAnimationFrame: The setInterval(renderFrame, ms) function runs the animation loop at steady fixed time increments, referencing the Six Revisions bouncing ball guide. Modern browsers also support window.requestAnimationFrame for monitor-synced refreshes; both methods can be selected and compared above.
  5. Euclidean Hit-Testing: When a mouse click occurs, screen coordinates are translated to canvas space using getBoundingClientRect() and normalized for canvas CSS scaling. The Euclidean distance between click coordinates (x_m, y_m) and object center (x, y) is evaluated using Math.hypot(x_m - x, y_m - y). If this distance is less than or equal to the object's radius, a Direct Hit is registered, triggering the selected visual effect and particle explosion!
